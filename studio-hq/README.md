# Studio HQ: art

© 2026 justaskjoe. All rights reserved.

Studio HQ is the crew's front door: one signed-in page drawn as a painted village (https://jaj-forge.huntefl.workers.dev). Its code lives in the private `JustAskJoe/forge` repo. This folder holds only its **art requests**, so the Artist agent can sketch new looks for it the same way she does for the games.

**Status:** three painted looks are live (Revachol, Revachol on Acid, Cozy) plus the drawn Sketch look. Six new looks are being sketched (see `art/art-direction.md`). Every look the crew keeps becomes an option in Studio HQ's ⚙ Settings menu.

Not a game: it isn't in `games.json`, so it has no Lab build or Arcade cabinet.
