START TONIGHT

From idea to a playable hand in two evenings.

EVENING 1 · RULES

Lock the rules

One four-seat ruleset: 152 tiles, the Swap, calls, Mimics and an 8-hand starter card, written up as the prototype rules sheet.

EVENING 1 · CODE

A headless engine

A new Vite + TypeScript project. Claude Code writes the rules, the card checker, tests and a simple bot. Four bots play 1,000 games; one command prints how long hands run and which card hands win.

EVENING 2 · SCREEN

One table you can play

You against three bots, placeholder tiles, the Ready counter and a hint button; the painted art comes later. Send the link to one friend who plays mahjong.

The only question that matters tonight: can a beginner finish a hand, and does it feel tense?
