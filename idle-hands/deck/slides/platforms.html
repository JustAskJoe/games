Why one web codebase: it ships as a website, wraps into iOS and Android apps, and wraps again for Steam, so the game is built once. A phone still matters most because a PC-only build can't remind you when the computer is off. For XR, frameworks like WebSpatial turn a React web app into a spatial app on supported headsets, and the 3D models behind the sprites become the tabletop town. The automation engine lives on the server, so every platform is just another view of the same town.
