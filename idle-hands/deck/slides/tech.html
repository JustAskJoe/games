The engine runs on the server, separate from the town, so every client (web, phone, Steam, XR) reads the same record of what ran. A managed integration platform (Composio, Nango or Pipedream Connect class) handles connect-your-account flows and token storage, which keeps the most security-sensitive piece off our own code. Model routing is the cost lever: Claude Haiku 5.5 handles high-volume routine runs at $0.10 per million input tokens and $0.50 per million output; Claude Sonnet 5.5 at $2 / $10 builds agents and handles errands. Prompt caching and batch processing cut further. Connectors follow the open Model Context Protocol where available, so new integrations don't need custom code each time.
