Assumptions. Prices: Claude Haiku 5.5 $0.10 in / $0.50 out per million tokens; Claude Sonnet 5.5 $2 / $10 (Anthropic pricing page, Oct 2026). Routine run = 20K input + 2K output tokens on Haiku. Agent build = 50K in + 5K out on Sonnet. Errand = 120K in + 6K out on Sonnet. Hosting $0.40 per payer per month (our estimate). Store fee 15% (small-business / second-year subscription rate). Margins are before caching and batch discounts, so real costs should come in lower. Energy top-up = 10 errands for $5.99, $3.00 cost. Heavy user = 300 runs, 10 builds, 8 errands. Operator letters add about 2¢ for a typical town (see Cost per player by town size).
